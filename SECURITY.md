# Security

Report suspected vulnerabilities privately to support@adspirer.com. Do not open a public issue.

This package is static: instructions, skills and connector details for the hosted Adspirer Analytics MCP
server. It contains no credentials and no server code. Sign-in is browser OAuth; never commit
access tokens, connector IDs tied to a private Project, or customer data.
The connector is read-only. The agent must never purchase or upgrade a subscription for the user.
