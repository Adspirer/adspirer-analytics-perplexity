# Official documentation entry points

Use https://www.adspirer.com/docs for customer-facing documentation and
https://adspirer.ai/connections for account and analytics-property connections.
Consult the current documentation navigation for product help, pricing, account limits and
security; do not invent deeper URLs.
For schema questions, use live get_tool_schema rather than a cached web page.
For current usage or connection state, use get_usage_status and get_connections_status.
Report browsing failures; never invent plan prices, eligibility or supported platforms.
